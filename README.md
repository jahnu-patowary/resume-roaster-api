# Resume Roaster API 🔥

An API that gives brutally honest, AI-powered feedback on your resume.

## Tech Stack
Node.js, Express

## Setup
bash
git clone https://github.com/jahnu-patowary/resume-roaster-api.git
cd resume-roaster-api
npm install




API_KEY=your_api_key_here
PORT=3000


Run:
bash
npm start


## API
**POST /roast**
json
